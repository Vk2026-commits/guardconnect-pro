# guardconnect-pro

I want to create a website for security officers to be able to log in and create a profile like LinkedIn, where they can put all of their information, and other security companies can come in and look at their page and see who they are, what their certifications are, and be able to hire them for new security jobs. I also want to add a page under their profile where they can have a live video interview that potential employees can look at.  This page should be able to be monetized where there will be a tiered login. The first tier, for an example, can be or you can just see the information generally for free. The second tier should be where you can interact and email the potential security officer. And the third one is where they can see all of the information, plus see all their certifications and can see the interview that was conducted via... The website.
